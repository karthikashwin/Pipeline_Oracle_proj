InkWave Publishing is a mid-sized book production and distribution company that manages daily operational data across several independent systems, including sales, production, distribution centres, and vendor performance. Because these datasets are stored in separate formats and updated by different departments, the organisation faces issues such as inconsistent data definitions, duplicated entries, incompatible date formats, and the lack of a single consolidated version of truth. These challenges limit InkWave’s ability to perform trend analysis, assess vendor effectiveness, monitor distribution centre performance, and support strategic decision-making.
The aim of this coursework project is to design and implement a complete data warehouse (DW) solution for InkWave Publishing using Oracle technologies. The DW integrates multiple raw CSV datasets into a unified star schema consisting of conformed dimensions (Time, Product, Distribution Centre, Vendor, Channel) and a central Fact table capturing daily operational performance. To achieve this, the project includes designing a Bus Matrix, developing staging tables, applying robust data cleansing logic, building ETL pipelines to load dimensions and facts, and delivering analytical SQL queries as defined in the assignment brief.
The implementation was carried out using Oracle Autonomous Database accessed through SQL Developer Web, with supplementary scripting in Python (oracledb) to demonstrate programmatic database connectivity. The final warehouse supports five core analytical requirements, including gross margin rankings, vendor cost trends, channel mix analysis, author performance insights, and identification of high-risk distribution centres. This report documents the design decisions, ETL processes, SQL implementations, results, and technical challenges encountered during development.
By consolidating operational, sales, and vendor metrics into a unified star schema, the data warehouse eliminates fragmentation between legacy systems and ensures a single version of truth. This enables InkWave to perform margin analysis, vendor trend monitoring, and distribution centre benchmarking with far greater accuracy. The resulting analytical insights support strategic planning across production, sales, and supply chain functions.
